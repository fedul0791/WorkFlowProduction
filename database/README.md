# Database

Локальная PostgreSQL запускается через сервис `db` в корневом `docker-compose.yml`. Данные находятся в именованном Docker volume `postgres_data` и переживают обычный `docker compose down`.

На этом этапе бизнес-таблицы не создаются. Alembic устанавливает таблицу версии миграций; первая пустая ревизия проверяет инфраструктурный путь миграции без фиксации бизнес-модели.
